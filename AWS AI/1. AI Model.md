
# 🔨🤖🔧 What _Amazon Bedrock_ Really Is

Think of **Amazon Bedrock** as:

> **A managed gateway (API layer) to multiple foundation AI models — without you managing infrastructure.**

### In plain terms:

- You don’t host models
- You don’t train from scratch
- You don’t manage GPUs
- You just **call an API and get AI output**

# 🧠 Key Concept: “Interface to AI Models”

The transcript says:

> “Bedrock is an interface to AI models hosted on AWS”

### What that actually means:

Instead of doing this ❌:

- Sign up for Anthropic
- Sign up for Meta
- Set up APIs individually
- Handle auth, billing, scaling separately

You do this ✅:

- Use **one AWS service (Bedrock)**
- Access **multiple models via one API**

# 🏗️ Architecture View (Important)

Here’s how it looks conceptually:

```
Your App (Lambda / EC2 / Backend)
        |
        v
   Amazon Bedrock API
        |
        +-------------------+
        |                   |
   Anthropic Claude     Meta Llama
        |                   |
   Cohere Command       Amazon Titan
```

👉 Bedrock acts as a **unified abstraction layer**


# 💰 Provisioned vs Serverless (VERY important)

The course mentions two modes:

## 1. Provisioned (💸 expensive)

- Dedicated throughput
- Reserved model capacity
    
- Used in production with high scale
    

## 2. Serverless (✅ what you’ll use)

- Pay per request
    
- No upfront cost
    
- Scales automatically
    

👉 Think:

- **Serverless = Lambda-style AI**
    
- **Provisioned = EC2-style AI**

# ⚠️ Fine-Tuning (Why it's expensive)

The instructor is right to warn you.

Fine-tuning involves:

- Training models on your data
    
- Requires GPUs
    
- Large datasets
    
- Long compute time
    

💸 Cost: **$10K+ easily**

---

# 🧠 Better Alternative (Used in Real Systems)

Instead of fine-tuning, we usually use:

## 👉 RAG (Retrieval-Augmented Generation)

```
User Query
   ↓
Search your data (via embeddings)
   ↓
Send relevant context to model
   ↓
Model responds with context-aware answer
```

💡 This is:

- Cheaper
- Faster
- Industry standard

# 🚀 What You Should Focus on First

Don’t worry about fine-tuning yet.

Focus on:

1. ✔️ Calling Bedrock APIs

2. ✔️ Prompt engineering
    
3. ✔️ Using different models
    
4. ✔️ Embeddings + search (super important)
