
# 🧠 1. What is Athena (Simple Mental Model)

> **Athena = SQL engine for S3**
- Data lives in **S3**
- Schema lives in **Glue Catalog**
- Queries run in **Athena**

# 🏗️ 2. Architecture (Very Important)

```text
S3 (data files)
     ↓
Glue Crawler → Data Catalog (table schema)
     ↓
Athena → SQL queries
```


# 🧪 3. How to Query Data on S3 (Step-by-Step)

Let’s use your `orders.csv` example.

---

## 🟢 Step 1: Upload Data to S3

```text
s3://your-bucket/raw/orders.csv
```

---

## 🟡 Step 2: Create Glue Crawler

- Data source → S3 path
    
- Run crawler
    

👉 Result:

```text
Database: ecommerce_db
Table: orders
```

---

## 🔵 Step 3: Open Athena

Go to:  
👉 **Amazon Athena → Query Editor**

---

## ⚙️ Step 4: Configure Query Result Location (IMPORTANT)

First time only:

👉 Set:

```text
s3://your-bucket/query-results/
```

👉 Athena stores query results here

---

## 🟣 Step 5: Select Database

Top dropdown:

```text
ecommerce_db
```

---

## 🟠 Step 6: Run Query

### Example 1: View Data

```sql
SELECT * FROM orders LIMIT 10;
```

---

### Example 2: Filter Data

```sql
SELECT * FROM orders
WHERE country = 'USA';
```

---

### Example 3: Aggregation

```sql
SELECT category, SUM(total_amount) AS revenue
FROM orders
GROUP BY category;
```

---

# 💰 4. How Athena Pricing Works

👉 You pay for **data scanned**

```text
~ $5 per TB scanned
```

---

## ❗ Example:

- File size: 1 GB
    
- Query scans full file → you pay for 1 GB

# 💡 5. How to Reduce Cost (VERY IMPORTANT)

---

## 🔥 1. Use Partitioning

Instead of:

```text
s3://bucket/orders.csv
```

Use:

```text
s3://bucket/orders/year=2026/month=04/
```

---

### Then query:

```sql
SELECT * FROM orders
WHERE year = 2026 AND month = 04;
```

👉 Only that partition is scanned ✔️

---

## 🔥 2. Use Columnar Formats (BIG WIN)

Convert CSV → Parquet

👉 Benefits:

- Less data scanned
    
- Faster queries 🚀
    

---

## 🔥 3. Select Only Needed Columns

❌ Bad:

```sql
SELECT *
```

✅ Good:

```sql
SELECT product_name, total_amount
```
