# 🧠 3. Key Concept

### ❗ Why API Gateway?

- Frontend (mobile/web) **cannot directly access DynamoDB**
- Lambda **cannot be directly exposed publicly**

👉 Solution:

```text
Client → API Gateway → Lambda → DynamoDB
```


# 🗄️ 4. Step 1: Create DynamoDB Table

- Table Name: `UsersTable`
- Partition Key: `userId (String)`
- Capacity: On-demand (default)


# 🧠 5. API Logic Concept

API Logic = backend code that:

- Creates user
- Fetches user
- Deletes user

### Where to write?

- Python 
### Where to host?

- AWS Lambda ✔️ (used here)


# 🧱 6. Lambda Design (Best Practice)

Create **separate Lambda functions**:

|Function Name|Purpose|
|---|---|
|createUserFunction|Create user|
|getUserFunction|Fetch user|
|deleteUserFunction|Delete user|

💡 Best Practice:

> One function = One responsibility (Separation of Concerns)


# 🔐 7. IAM Role for Lambda

### Why?

Lambda needs permission to access DynamoDB

### Role:

- Name: `LambdaDynamoDBExecutionRole`
- Policy: `AmazonDynamoDBFullAccess`

## 🟢 Create User Lambda


```
import json
import boto3
import os

dynamodb = boto3.resource('dynamodb')
table = dynamodb.Table('UsersTable')  # Exact name you created

def lambda_handler(event, context):
    try:
        body = json.loads(event['body'])
        user_id = body['userId']
        name = body['name']
        email = body['email']
        
        table.put_item(
            Item={
                'userId': user_id,
                'name': name,
                'email': email
            }
        )
        
        return {
            'statusCode': 201,
            'body': json.dumps({'message': 'User created successfully'})
        }
    
    except Exception as e:
        return {
            'statusCode': 500,
            'body': json.dumps({'error': str(e)})
        }
```

### Input 

```json
{
  "body": "{\"userId\":\"101\",\"name\":\"Bhavesh\",\"email\":\"test@example.com\"}"
}
```

### Output

```json
{
  "statusCode": 201,
  "body": "{\"message\": \"User created successfully\"}"
}
```

## 🔵 Get User Lambda


```
import json
import boto3

dynamodb = boto3.resource('dynamodb')
table = dynamodb.Table('UsersTable')

def lambda_handler(event, context):
    user_id = event['pathParameters']['userId']
    
    try:
        response = table.get_item(Key={'userId': user_id})
        
        if 'Item' in response:
            return {
                'statusCode': 200,
                'body': json.dumps(response['Item'])
            }
        else:
            return {
                'statusCode': 404,
                'body': json.dumps({'message': 'User not found'})
            }
    except Exception as e:
        return {
            'statusCode': 500,
            'body': json.dumps({'error': str(e)})
        }
```
### Input

```json
{
  "pathParameters": {
    "userId": "101"
  }
}
```


### Outputs

✔️ Success:

```json
{
  "statusCode": 200
}
```

❌ Not found:

```json
{
  "statusCode": 404
}
```


## 🔴 Delete User Lambda

```
import json
import boto3

dynamodb = boto3.resource('dynamodb')
table = dynamodb.Table('UsersTable')

def lambda_handler(event, context):
    user_id = event['pathParameters']['userId']
    
    try:
        table.delete_item(Key={'userId': user_id})
        return {
            'statusCode': 200,
            'body': json.dumps({'message': f'User {user_id} deleted successfully'})
        }
    except Exception as e:
        return {
            'statusCode': 500,
            'body': json.dumps({'error': str(e)})
        }
```
### Input

```json
{
  "pathParameters": {
    "userId": "101"
  }
}
```

### Output

```json
{
  "statusCode": 200,
  "body": "User deleted"
}
```

# 🌐 9. API Gateway Role

API Gateway acts as:

> 🚪 Entry point (Front Door)

### Responsibilities:

- Accept HTTP requests
- Route to correct Lambda
- Return response to client


# 🧩 10. Route Mapping

|Method|Route|Lambda Function|
|---|---|---|
|POST|/user|createUserFunction|
|GET|/user/{userId}|getUserFunction|
|DELETE|/user/{userId}|deleteUserFunction|


# ⚙️ 11. Create HTTP API

Steps:

1. Go to API Gateway
2. Choose **HTTP API**
3. Name: `UserAPI`
4. Use `$default` stage
5. Add routes 
```
POST /user
GET /user/{userId}
DELETE /user/{userId}
```

👉 At this stage:

- Routes exist
- But they **don’t do anything yet**

6. Attach Lambda integrations

```
Now you connect:

Route → Lambda Function

Example:

POST /user → createUserFunction

```

# 🔁 12. Full Request Flow

Example:

```text
POST /user
   ↓
API Gateway
   ↓
createUserFunction (Lambda)
   ↓
DynamoDB (store data)
   ↓
Response back to client
```
