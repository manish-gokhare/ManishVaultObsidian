# 🔷 1. What is Caching? (Core Idea)

👉 **Caching = storing frequently accessed data in a faster location**

Goal:

- ⚡ Faster response time
- 💸 Lower cost
- 📉 Reduced database load

# 🔷 3. Why Caching Reduces Cost 💸

### Example 1: Database Queries

Without cache:

```text
App → DB → Response (every time)
```

With cache:

```text
App → Cache → (hit ✅)
         ↓
        DB (only if miss ❗)
```

✔️ Fewer DB queries  
✔️ Smaller DB instance needed

---

### Example 2: Static Content

Without cache:

- Server sends image every time ❌
    

With cache:

- Browser/CDN serves it ✅
    

✔️ Saves bandwidth  
✔️ Reduces server load

# 🔷 4. What is Amazon ElastiCache?

👉 **ElastiCache = Managed Distributed In-Memory Cache**

- Stores data in **RAM (not disk)**
- Extremely fast (microseconds latency ⚡)


### 🧠 Architecture with ElastiCache

```text
Application
    ↓
ElastiCache (Redis / Memcached)
    ↓
RDS / Aurora
```

---

# 🔥 5. How It Works (Lazy Loading Strategy)


## ✅ Lazy Loading (Cache-Aside Pattern)

### Step-by-step:

```text
1. App requests data
2. Check Cache
   ├── HIT → return data ✅
   └── MISS → query DB ❗
                ↓
             store in cache
                ↓
             return data
```

---

### 💡 Key Point

👉 Cache is filled **only when needed**

✔️ Efficient  
❗ Requires **application code changes**

---

# ⚠️ Important Concept (Exam + Real World)

> ❗ Unlike RDS Proxy, ElastiCache is NOT transparent  
> 👉 You MUST modify application logic

# 🔷 6. Other Caching Strategies

---

## ✅ 1. Lazy Loading (we covered)

✔️ Load on demand  
❗ First request is slow

---

## ✅ 2. Write-Through

```text
App writes → Cache + DB (simultaneously)
```

✔️ Cache always updated  
✔️ Fast reads  
❗ Slightly slower writes

---

## ✅ 3. TTL (Time To Live)

```text
Cache entry → expires after X seconds
```

✔️ Prevents stale data  
✔️ Automatic cleanup

# 🧪 Example Code (Python – Fully Working) 🔨🤖🔧

This shows exactly how app connects both:

```python
import redis
import pymysql
import json

# Connect to Redis (ElastiCache)
cache = redis.Redis(
    host='my-redis.xxxxxx.use1.cache.amazonaws.com',
    port=6379,
    decode_responses=True
)

# Connect to RDS
db = pymysql.connect(
    host='mydb.xxxxxx.us-east-1.rds.amazonaws.com',
    user='admin',
    password='password',
    database='shop'
)

def get_product(product_id):
    cache_key = f"product:{product_id}"

    # 1. Check Cache
    cached_data = cache.get(cache_key)

    if cached_data:
        print("Cache HIT ✅")
        return json.loads(cached_data)

    print("Cache MISS ❗ Querying RDS...")

    # 2. Query RDS
    with db.cursor() as cursor:
        cursor.execute("SELECT id, name, price FROM products WHERE id=%s", (product_id,))
        result = cursor.fetchone()

    if result:
        data = {
            "id": result[0],
            "name": result[1],
            "price": float(result[2])
        }

        # 3. Store in Cache (TTL = 60 sec)
        cache.setex(cache_key, 60, json.dumps(data))

        return data

    return None


# Example call
print(get_product(101))
```
